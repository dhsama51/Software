# 26-1 AI Hardware

인공지능하드웨어 수업에서 진행한 과제들을 정리한 폴더입니다.
AI 모델의 연산이 하드웨어 관점에서 어떻게 처리되는지 이해하기 위해 matrix multiplication, tiling, dataflow, systolic array 등을 실습했습니다.

## Assignments

| Assignment | Topic                             | Description                                                                                 |
| ---------- | --------------------------------- | ------------------------------------------------------------------------------------------- |
| Practice 1 | Matrix Multiplication with Tiling | Convolution lowering과 matrix tiling을 적용하고, tile size 및 `np.matmul` 사용 여부에 따른 실행 시간을 비교했습니다. |
| Practice 2 | Dataflow & Systolic Array         | GEMM 연산의 dataflow별 메모리 접근량을 분석하고, 간단한 systolic array 동작을 구현했습니다.                            |

## Keywords

`AI Hardware` `Matrix Multiplication` `Tiling` `Dataflow` `Systolic Array`
